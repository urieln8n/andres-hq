# Instrucciones para Claude en este proyecto

- Lee `README.md` antes de nada: ahí están el estado y el siguiente paso.
- Este proyecto está registrado en el cuartel general (`~/proyectos/andres-hq`). Al terminar
  la sesión, actualiza allí su entrada en `proyectos.json`, añade una línea a `BITACORA.md`,
  ejecuta `node scripts/generar.mjs` y haz commit + push de los dos repos.
- Actualiza también "Siguiente paso" en el `README.md` de este repo.
- Las ideas nuevas que salgan van a `andres-hq/IDEAS.md`, no a este repo.
- Nunca subas claves ni datos de clientes: van en `.env`.
